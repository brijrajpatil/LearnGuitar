# Milestone reviews

Each milestone ends with a week of real practice, then a short written review. The review decides what changes before the next milestone starts, and any decision it makes goes into the brief's decision log.

Name each review `milestone-N.md`. Write it from what happened in practice, with dates and numbers where there are any.

```markdown
# Milestone N review: title

Dates: YYYY-MM-DD to YYYY-MM-DD

## What shipped

What the milestone delivered, compared with what the brief planned for it.

## How I used it

Practice sessions that week, songs, sections, levels and tempos reached.

## Against the targets

Each target in the brief's "How to tell it's working", and where it stands.

## What helped

## What got in the way

## Changes for the next milestone

What to add, cut or change, and why. Link any new decision note.
```
