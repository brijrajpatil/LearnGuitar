# Docs

How Song Practice was framed and decided, written down as it was built. The code is in [`app/`](../app/).

Read them in this order:

1. [Product brief](product/product-brief.md): the problem, who the app is for, goals, features, architecture and the six milestones.
2. [Decisions](decisions/): one note per choice that had alternatives, with the options and the reason for the pick. The index marks each note's area: product, design or tech. Notes are never rewritten. When a decision changes, a later note supersedes it.
3. [Milestone reviews](product/reviews/): what a week of real practice showed after each milestone, and what changed because of it. The first comes after milestone 1.
